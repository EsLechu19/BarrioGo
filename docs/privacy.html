Política de privacidad

BarrioGo conecta a clientes con negocios de barrio. Esta política explica qué datos utiliza la aplicación y con qué servicios se transmiten.

Última actualización: 27 de noviembre de 2026. Para consultas sobre privacidad, escribe a jotah26.dev@gmail.com.

Datos de cuenta y perfil

Para crear una cuenta o iniciar sesión se utiliza Firebase Authentication. Tratamos el nombre, el correo electrónico y el identificador de cuenta; si eliges registrarte con correo, Firebase gestiona la credencial de acceso. También puedes iniciar sesión con Google de forma opcional: Google proporciona una credencial a Firebase y BarrioGo utiliza el nombre y correo de esa cuenta. El teléfono y la foto de perfil se añaden solo si decides proporcionarlos. El perfil se guarda en Firebase Firestore; algunos datos de perfil también se conservan en el dispositivo.

Direcciones, ubicación y mapas

Las direcciones que guardas para elegir una entrega se conservan en el almacenamiento local del dispositivo. Al confirmar un pedido, la dirección seleccionada y, si existen, sus coordenadas se guardan con el pedido en Firebase Firestore para gestionar la entrega. Puedes indicar una dirección o un punto en el mapa; el acceso al GPS requiere tu permiso y se usa para ayudarte a ubicarte.

El mapa utiliza MapLibre y descarga mapas de OpenFreeMap. Al buscar una dirección o convertir un punto del mapa en una dirección, BarrioGo envía la dirección o las coordenadas a Nominatim, un servicio de OpenStreetMap. Los negocios también pueden publicar la dirección y ubicación de su local.

Pedidos, pagos y contenido que eliges publicar

Los pedidos se guardan en Firebase Firestore con el identificador de usuario, negocio, productos, cantidades, importes, método de pago, estado y dirección de entrega. Estos datos permiten al negocio preparar y gestionar el pedido. Si publicas una opinión, guardamos su valoración, texto, nombre e identificador de cuenta.

El pago de prueba de Mercado Pago es opcional y abre un checkout externo. Para iniciar ese pago, BarrioGo envía al servicio de pagos los identificadores de pedido; el backend transmite a Mercado Pago el correo verificado del comprador, los productos y el importe. BarrioGo no recibe ni almacena números de tarjeta. Los datos que introduces directamente en el checkout de Mercado Pago se rigen también por las condiciones de ese servicio.

Fotografías y notificaciones

Si eliges una foto de perfil, negocio o producto, la imagen se sube a Cloudinary y su dirección web se guarda con el perfil, negocio o producto en Firestore. No se suben fotos de tu galería sin que las selecciones.

Si autorizas las notificaciones, la aplicación obtiene un token de Expo Push y lo guarda en tu perfil de Firestore para poder enviar avisos de pedidos. Cuando se utiliza el servicio de notificaciones, el token y el contenido del aviso se transmiten a Expo y a los servicios de entrega de notificaciones del dispositivo. El historial de avisos de la aplicación se guarda localmente.

Conservación y eliminación

Mantenemos los datos de cuenta y servicio mientras sean necesarios para operar BarrioGo o hasta tramitar una solicitud de eliminación. Tras solicitar la eliminación de la cuenta, los datos de pedidos y pagos se conservan durante 90 días para resolver incidencias y luego se eliminan o anonimizan. El proceso se realiza manualmente; esta página no borra datos por sí sola. Las direcciones y avisos guardados solo en el dispositivo deben borrarse en ese dispositivo.

Puedes iniciar la solicitud y conocer exactamente qué datos se eliminan en Eliminar cuenta de BarrioGo.

Contacto
